# Galastar

> 可视化 Galgame 创作引擎 —— 在浏览器里写剧本、排立绘、接分支，一键打包成双击即玩的 Web 作品。

Galastar 把「做一部 Galgame」拆成三步：**搭舞台 → 写台词 → 打包**。不需要写一行 JSON，也不需要装任何东西；作品和素材都存在本机浏览器里，导出的产物是纯静态文件，断网也能玩。

## 它现在能做什么

| 能力       | 说明                                                                                        |
| ---------- | ------------------------------------------------------------------------------------------- |
| 可视化剧本 | 场景 → 帧。每帧一句台词或一个分支，按顺序列出整幕                                           |
| 实时预览   | 编辑器中间就是真正的播放器，改一个字、换一张背景，舞台上立刻可见                            |
| 立绘调度   | 左 / 中 / 右三个站位，每个角色挂多套表情，说话的人自动提亮、其他人压暗                      |
| 演出       | 背景淡入 / 溶接 / 闪白 / 上升四种转场，可加震屏与一次性音效                                 |
| 分支       | 选项跳转到任意场景，可写入「标记」；跳转帧可以按条件分流                                    |
| 角色语音   | 逐句挂语音，自动播放模式会等语音读完再翻页                                                  |
| 玩家侧功能 | 标题界面、逐字机、自动 / 快进、回看记录、6 格存读档、音量与文字速度设置、全屏               |
| 界面皮肤   | 默认 **PGF**（初代界面，取法 NEKOPARA 的排版），可切到 **夜航**（暗底衬现代版）             |
| 打包       | 导出 Web Zip（`start.html` + 播放器 + `media/`），也可导出 `.galastar` 工程包换设备继续编辑 |
| 撤销重做   | 80 步撤销栈，Ctrl+Z / Ctrl+Shift+Z                                                          |

## 快速开始

```bash
nvm use            # 读 .nvmrc，固定 Node 24
pnpm install       # 包管理器只用 pnpm（有 pnpm-lock.yaml）
pnpm dev           # http://localhost:5173
```

不想先跑编辑器？[`samples/galastar-demo-web.zip`](samples/galastar-demo-web.zip) 就是示例作品的打包产物——解压后双击 `start.html`，断网也能玩，可以先看看成品长什么样。

环境：**Node 24**（`.nvmrc` 已钉）+ **pnpm**（有 `pnpm-lock.yaml`，别用 npm/yarn 混装；`pnpm-workspace.yaml` 里固定了 `nodeLinker: hoisted`，原因见 [`docs/DECISIONS.md`](docs/DECISIONS.md) 的 D8）。首次打开会自动生成一部示例作品《星のかけら》，包含 4 幕、2 个角色、一条分支和一个结局，用来对照学习；示例里的立绘是程序生成的剪影占位图，导入自己的 PNG 即可替换。

常用命令：

```bash
pnpm dev         # 本地开发
pnpm build       # 生产构建（产物在 dist/）
pnpm preview     # 预览构建产物
pnpm check       # 格式 + lint + 类型检查（vp check）
```

依赖用 **pnpm**，构建与检查统一走 **vp（Vite+）**；`base` 由 CI 的 `PAGES_BASE_PATH` 注入，本地恒为 `/`。

## 打包出来的东西长什么样

点编辑器右上角「打包作品 → 打包并下载」，得到一个 zip：

```
start.html        ← 解压后双击它就能玩
galastar.js       ← 播放器运行时（与编辑器预览是同一份代码）
galastar.css
data.js           ← 剧本 + 素材索引，以 <script> 注入
media/            ← 背景、立绘、音乐、语音、音效，原格式原文件名
README.txt        ← 给玩家看的操作说明
```

两个关键设计让它能**双击即玩**：

1. 数据用 `data.js`（`window.GALASTAR_DATA = {...}`）注入，而不是 `fetch` JSON —— `file://` 协议下 `fetch` 会被 CORS 拦掉。
2. 运行时是 classic script（无 `import` / `export`），素材全部相对路径 —— 不依赖本地服务器。

## 界面皮肤：默认是 PGF

播放器默认穿的是 PGF——这套界面来自初代原型，当年照着 NEKOPARA 的排版手写的，算是夹带私货：

- 台词不上对话框，白字配暗红描边**直接压在画面上**
- 画面本身糊 4px，人物才是清晰的，字也才读得下去
- 画面底部一层白色渐隐，把人下半身和文字一起沉进薄雾
- 说话的人亮着，其余立绘压到 42% 亮度
- 系统菜单藏在右下角，字色淡到几乎看不见，鼠标过去才浮出来
- 选项是一根暗红横条 + 1px 白边，选中时先闪成白纸黑字再沉回近黑
- 句尾那颗一闪一闪的 ● 就是「点一下继续」

想换材质：**项目设置 → 界面皮肤** 切到「夜航」——同一套骨架，背景不糊、台词落到暗色底板上、菜单回到右上角、按钮跟随主题色，适合画面偏暗或偏写实的作品。切换后舞台立刻更新，打包时跟着作品一起导出，玩家那边零配置。

## 核心概念

```
作品 Project
├── 场景 Scene        一幕的容器，自带播放顺序
│   └── 帧 Frame      台词的原子单位，四种类型
│       ├── line      台词帧：说话人 / 台词 / 背景 / 音乐 / 立绘 / 转场
│       ├── choice    选择帧：若干选项，各自跳转并写入标记
│       ├── jump      跳转帧：条件成立才跳，否则顺延下一帧
│       └── end       结束帧：本章完 / 结局，可衔接下一场景
├── 角色 Character    名字、名字牌颜色、表情 → 立绘资产的映射
├── 标记 Flag         键值对，选项写入、条件读取
└── 素材 Asset        背景 / 立绘 / 音乐 / 语音 / 音效，二进制存在 IndexedDB
```

### 帧是完整快照，不是增量补丁

这是 v2 最重要的模型决策：**每一帧都完整记录当时的舞台状态**（背景、立绘、音乐），而不是「只写变化的部分」。

```json
{
  "id": "f_x1",
  "type": "line",
  "speaker": { "characterId": "c_haruka", "name": "青井 遥" },
  "text": "你居然真的爬上来了。",
  "bg": "a_dusk",
  "bgm": null,
  "sfx": null,
  "voice": null,
  "cast": {
    "left": null,
    "center": { "characterId": "c_haruka", "expression": "平静" },
    "right": null
  },
  "transition": "fade",
  "shake": false
}
```

好处：剧本能单独读懂、单独复制、单独撤销；播放器不需要「合并补丁」，也就不会因为漏字段而黑屏。新建帧时编辑器会自动继承上一帧的舞台，所以写起来并不更啰嗦。

## 编辑器快捷键

| 快捷键                            | 作用                         |
| --------------------------------- | ---------------------------- |
| `Ctrl/⌘ + S`                      | 立即保存（平时也会自动保存） |
| `Ctrl/⌘ + Z`                      | 撤销                         |
| `Ctrl/⌘ + Shift + Z` / `Ctrl + Y` | 重做                         |
| `Ctrl/⌘ + Enter`                  | 在台词输入框里新建下一句     |

## 玩家侧操作

| 操作                   | 作用                         |
| ---------------------- | ---------------------------- |
| 点击画面 / 空格 / 回车 | 继续（正在逐字时先补全本句） |
| 按住 `Ctrl`            | 快进                         |
| `A`                    | 自动播放                     |
| `L`                    | 回看已读台词                 |
| `S`                    | 存 / 读档                    |
| `F`                    | 全屏                         |
| `Esc`                  | 设置                         |

## 部署到 GitHub Pages

仓库已带 `.github/workflows/deploy.yml`：push 到 `main` 后自动 `vp check → vp build → deploy`。

- 项目页（`https://<user>.github.io/<repo>/`）：不用配置，CI 自动取仓库名做前缀。
- 用户页 / 自定义域：在 **Settings → Variables → Actions** 新建 `PAGES_BASE_PATH`，值填 `/`。

## 边界与注意事项

- **没有服务端**。作品与素材都在本机浏览器的 IndexedDB 里，换浏览器 / 清缓存就会丢，所以请定期「导出工程备份包」。
- 素材按原格式打进 zip，不做压缩转码。想控制体积，请自行把背景压成 JPEG、音乐压成 MP3。
- 编辑器按桌面宽屏设计（≥ 1280px 体验最佳），暂不适配手机。
- 导出作品支持手机浏览器，但立绘与文字按 1280×720 等比缩放，横屏体验更好。

## 从 v1 到 v2

v1 是一个只能手写 JSON 的原型：用表单拼帧描述，播放器靠 `eval()` 执行分支里的 JS 字符串，既没有编辑器也没有打包。v2 把这条链路补全成「编辑 → 预览 → 打包」，同时把 v1 的界面语言（PGF，见上文）继承下来作为默认皮肤；旧实现已随 v2 发布移除，避免两套播放语义在同一仓库里并存。

更多设计细节见 [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) 与 [`docs/DECISIONS.md`](docs/DECISIONS.md)。
